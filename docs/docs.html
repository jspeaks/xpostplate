Docs

A public X post, or one you fabricate and override, drawn as a PNG.

Install

  • npmnpm i -g xpostplate
  • Homebrewbrew tap jspeaks/xpostplate && brew install --HEAD xpostplate
  • pnpmpnpm add -g xpostplate
  • Bunbun add -g xpostplate
  • npxnpx xpostplate --help
  • Sourcegit clone https://github.com/jspeaks/xpostplate && cd xpostplate && npm link

Then run xpostplate --help. npx runs it once without a global install. Homebrew is HEAD-only from the tap; a stable non-HEAD install needs a GitHub release.

Views

  • --view detailopened post as x.com shows it (default): avatar, check, photos, time · date · views
  • --view timelinehome-feed row with relative time
  • --view quotenested post, inset, no action bar
  • --view platebordered broadcast card (near-black border, X mark, initials)

No flags means the faithful opened post: light theme, no border, no X mark, real avatar (initials as fallback), verified check from the post data, blue @mentions and links, photos drawn, and counts only when the source has them. The old primitive plate is --view plate --no-media; add --accent '#1D9BF0' for its old blue border.

Flags

  • --fabricateinvent a post from --text; no URL, no network
  • --name--handle--textoverride identity and body
  • --verified--no-verifiedshow or hide the check
  • --postedoverride the timestamp (ISO)
  • --replies--reposts--quotes--likes--bookmarks--viewscount overrides (zero counts as real)
  • --media--no-mediaphotos under the text (default on); --no-media is text only and keeps the media link
  • --theme light|darkdefault light; dark is x.com Lights out (true black)
  • --mark--no-markX mark; on for plate, off for the other views
  • --border--accent--radiusplate frame; accent defaults to near-black
  • --max-heightdrop photos before body lines
  • -owrite PNG to a file; omit on a TTY for {handle}-{YYYYMMDD-HHMMSS}.png (x-… if fabricate/missing handle); - = stdout
  • --jsonprint the post JSON, skip the image
  • --fixturerender local JSON instead of fetching

Leave X_BEARER_TOKEN unset and a public post still loads from X's syndication feed. Counts that feed does not carry stay off the image. xpostplate --help lists every flag.

Examples

The opened post as x.com shows it, photos included. No token.
xpostplate https://x.com/SpaceX/status/[slug] > post.png
Home-feed row, dark.
xpostplate https://x.com/SpaceX/status/[slug] --view timeline --theme dark -o timeline.png
The old broadcast plate: border, X mark, text only.
xpostplate https://x.com/SpaceX/status/[slug] --view plate --no-media -o plate.png
Quote only.
xpostplate https://x.com/SpaceX/status/[slug] --view quote -o quote.png
Invent a post. No URL and no network.
xpostplate --fabricate --name "SpaceX" --handle SpaceX --text "Starship is stacked." --view timeline
Start from a public post and replace the words.
xpostplate https://x.com/SpaceX/status/[slug] --text "A line written for the image."

Post JSON

--json prints this shaped post. --fixture accepts the same flat shape, or the X API envelope (data + includes.users) like fixtures/sample-post.json. Counts may be numbers or null (hidden). --fabricate builds the same fields from flags.

Requirements

Homebrew (HEAD tap) pulls in Node and ImageMagick for you. With npm, pnpm, or Bun you need Node 18 or newer, and ImageMagick (magick) on PATH: brew install imagemagick or apt install imagemagick.
