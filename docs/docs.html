Docs

A public X post, or one you fabricate and override, drawn as a PNG.

Install

ImageMagick magick is required and must be on PATH. Node 18 or newer.

node bin/xpostplate.js --help

When published: npm install -g xpostplate. Homebrew is head-only via packaging/homebrew/xpostplate.rb.

Views

  • --view plate· bordered broadcast card (default)
  • --view timeline· home-feed row with relative time
  • --view detail· opened post with clock time and views
  • --view quote· nested post, inset, no action bar

Flags

  • --fabricate· invent a post from --text; no URL, no network
  • --name --handle --text· override identity and body
  • --verified / --no-verified· show or hide the check
  • --posted· override the timestamp (ISO)
  • --replies --reposts --quotes --likes --bookmarks --views· count overrides (zero counts as real)
  • --media· draw photos under the text
  • --theme light|dark· plate theme (default light)
  • --max-height· drop photos before body lines
  • -o· write PNG to a file (default stdout)
  • --json· print the post JSON, skip the image
  • --fixture· render local JSON instead of fetching

Leave X_BEARER_TOKEN unset and a public post still loads from X's syndication feed. Counts that feed does not carry stay off the image. xpostplate --help lists every flag.

Examples

# Broadcast plate. No token. Photos stay off.
xpostplate https://x.com/SpaceX/status/21…47 > plate.png

# Home-feed row, dark, with photos.
xpostplate https://x.com/SpaceX/status/21…47 --view timeline --theme dark --media -o timeline.png

# Opened post.
xpostplate https://x.com/SpaceX/status/21…47 --view detail --theme dark -o detail.png

# Quote only.
xpostplate https://x.com/SpaceX/status/21…47 --view quote -o quote.png

# Invent a post. No URL and no network.
xpostplate --fabricate --name "SpaceX" --handle SpaceX --text "Starship is stacked." --view timeline

# Start from a public post and replace the words.
xpostplate https://x.com/SpaceX/status/21…47 --text "A line written for the plate."
