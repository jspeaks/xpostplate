CLI

Turn a public X post into a PNG.

Screenshot tools scrape markup X already broke. This reads the post and draws the plate.

plate · timeline · detail · quote

xpostplate https://x.com/SpaceX/status/21… > plate.png

Example only. The ellipsis is not a status id, so this line does not run.

Views

  • plate Bordered broadcast card.
  • timeline Home-feed row.
  • detail Opened post.
  • quote Nested post.

--fabricate invents a post from --text, with no URL and no network.

Photos are drawn only with --media.

The program is bin/xpostplate.js in this repo.
