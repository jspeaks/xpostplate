Turn an post into a PNG.

A CLI tool for turning an X post into a PNG.

xpostplate https://x.com/SpaceX/status/[slug] > post.png

A plate is the bordered broadcast card. Install docs · Homebrew HEAD: brew tap jspeaks/xpostplate && brew install --HEAD xpostplate

  • --view platebroadcast card
  • --view timeline timeline row format
  • --view detail detail post format (default)
  • --view quote quote only format
  • --fabricateinvents a post
  • --no-mediatext only
