Turn an post into a PNG.

A CLI tool for turning an X post into a PNG.

plate · timeline · detail · quote

xpostplate https://x.com/SpaceX/status/21… > plate.png

Example only. The ellipsis is not a status id, so this line does not run.

A plate is the bordered broadcast card.

  • --view plate· broadcast card
  • --view timeline· timeline row format
  • --view detail· detail post format
  • --view quote· quote only format
  • --fabricate· invents a post
  • --media· draws the photos
