# Project notes

Working notes for xpostplate, kept alongside the code. This folder is not published (the site serves only `docs/`).

- [tasks.md](tasks.md): open, in-progress, and done work
- [findings.md](findings.md): things we learned, verified, or measured
- [discussion.md](discussion.md): open questions and decisions, with dates
- [launch.md](launch.md): launch plan and drafts awaiting approval
- FAB (Features, Advantages, Benefits): the canonical copy is [docs/FAB.md](../docs/FAB.md), which feeds the site's `/fab` page

Conventions: conventional commits, semver in `package.json`. Notes-only changes use `docs(notes):` and don't bump the version; releases bump it and update CLI, `--help`, homepage, docs, FAB, timeline, README, SKILL.md, and the packaging formula in one pass.
